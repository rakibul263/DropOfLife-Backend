# DropOfLife Backend API (জীবনের এক ফোঁটা)
> Emergency Blood Donation & Real-time Dispatch REST API

## Overview
DropOfLife is a real-time blood donation and emergency dispatch service connecting patients in critical need with nearby eligible blood donors.

## Architecture
- **Runtime**: Node.js & TypeScript
- **Framework**: Express.js
- **State Store**: Reactive In-Memory Data Store (fast-path telemetry)
- **Database**: PostgreSQL / Prisma ORM
- **Security**: JWT Authentication & RBAC

## Development Setup
```bash
npm install
npm run dev
```
